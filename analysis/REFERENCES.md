## What this list is not

This is a defensible starting bibliography assembled via targeted web
search to replace placeholder citation tags, not a systematic literature
review. It covers exactly the claims this manuscript currently makes —
it does not represent a survey of the solopreneurship/self-employment
field, and a real literature review would likely surface additional,
more central sources (particularly anything specific to "solopreneur" or
"digital nomad" as a construct, which this search-based pass did not
turn up in peer-reviewed form). Treat it as a floor, not a ceiling,
before submission.
