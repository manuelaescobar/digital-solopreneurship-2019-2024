# Digital Solopreneurship: A Multi-Source Exploratory Analysis

Code and manuscript materials for *"The Solopreneur Share Is Falling, Not
Rising: Evidence from Self-Employed Software Developers, 2019–2024."*

**Authors:** Yurleidy Cossio-Restrepo, Manuela Escobar-Sierra, Francisco
Javier Arias Vargas.

## Repository structure

```
data_collection/   API-based ingestion pipeline for 6 public data sources
                    (World Bank, Eurostat, Census Nonemployer Statistics,
                    GitHub, OpenAlex, Stack Overflow Developer Survey)
                    -> data_collection/README.md for setup and usage

analysis/           Data audit, cleaning, and the three statistical
                    analyses reported in the manuscript (macro panel FE,
                    logistic trend, MICE income-gap model), plus the
                    manuscript drafts themselves:
  scripts/            01-05, run in order to reproduce all results
  data/               cleaned per-source tables (regenerated by scripts/02,
                      not committed — see .gitignore)
  outputs/tables/     result tables (CSV) underlying every number in the
                      manuscript
  outputs/figures/    the two figures in Results
  *.md                manuscript sections in draft form (see below)
```

## Reproducing the analysis

```bash
cd data_collection && python3 -m pip install -r requirements.txt
cp .env.example .env   # fill in your own free API keys — see that README
python3 scripts/openalex_ingest.py
python3 scripts/worldbank_ingest.py --start 2005 --end 2024
python3 scripts/eurostat_ingest.py --start 2010 --end 2024
python3 scripts/github_ingest.py
python3 scripts/census_nes_ingest.py --year 2021 --geo state
# Stack Overflow Survey: download via kagglehub — see data_collection/README.md

cd ../analysis
python3 scripts/01_audit_data.py
python3 scripts/02_build_clean_subtables.py
python3 scripts/03_macro_panel.py
python3 scripts/04_trend_analysis.py
python3 scripts/05_income_gap_mice.py
```

Python 3.9; key packages: pandas, statsmodels 0.14.6, linearmodels 6.1,
scikit-learn, scipy. A fixed random seed (`np.random.seed(42)`) makes the
MICE-based results in `05_income_gap_mice.py` exactly reproducible.
